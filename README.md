ZIPURL - Fast & Simple URL Shortener

ZIPURL is a lightweight, high-performance URL shortener designed to make long web addresses clean, manageable, and easy to share.

🚀 What ZIPURL Does

Instant Link Shortening: Transforms long, cumbersome URLs into compact, unique short links.

Fast Redirections: Uses modern caching strategies to ensure instant redirects when users click on a shortened link.

Clean UI: Simple and intuitive interface for quick link generation without unnecessary clutter.

Custom Subdomain Integration: Serves reliable short links directly under a custom domain structure (zipurl.ujwalsharma.space).

🛠️ Tech Stack & Overview

ZIPURL is built using a modern full-stack monorepo architecture designed for reliability and speed:

Frontend: Built with Next.js and styled with Tailwind CSS for a fast, responsive user experience. Hosted on Vercel.

Backend: Powered by a Node.js & Express REST API handling incoming link generation and redirection logic. Hosted on Render.

Database & Storage: Uses PostgreSQL (Neon) for persistent URL storage and Redis (Upstash) for sub-millisecond redirect caching.

📋 How to Use

Open https://zipurl.ujwalsharma.space.

Paste your original long URL into the input field.

Click Shorten (or Generate) to produce your shortened link.

Copy and share your generated short URL anywhere!
